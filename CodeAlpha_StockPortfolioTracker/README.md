# CodeAlpha Stock Portfolio Tracker

A console-based portfolio calculator using hardcoded sample stock prices.

## Features
- Lets the user enter stock symbols and quantities.
- Calculates each holding's value and the total portfolio value.
- Saves entries to `portfolio.csv`.
- Validates unknown symbols and invalid quantities.

## Requirements
- Python 3.8 or newer
- No external packages required

## Run
```bash
python main.py
```

## Sample price list
AAPL: $180, TSLA: $250, MSFT: $420, GOOGL: $175, AMZN: $190.
These are hardcoded example prices, not live prices.

## Concepts used
Dictionaries, input/output, loops, validation, arithmetic, CSV file handling.
